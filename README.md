# 개성화 지도

칼 융의 분석심리학으로 **내면의 무의식**을 살펴보는 자기탐색 도구.
성격 유형을 맞히는 검사가 아니라, 의식이 밀어낸 것을 되찾는 과정(개성화)의 출발점을 잡는다.

## 이론 구조

| 단계 | 융 개념 | 문항 |
|---|---|---|
| 1 | 태도 — 외향 / 내향 | 선택 4 |
| 2 | 네 기능 — 사고·감정·감각·직관 | 선택 12 (6쌍 × 2) |
| 3 | 페르소나 (사회적 가면) | 복수선택 + 직접입력 |
| 4 | 그림자 (투사) | 복수선택 + 직접입력 |
| 5 | 황금 그림자 (못 산 가능성) | 복수선택 + 직접입력 |
| 6 | 자기(Self) — 몰입의 순간 | 복수선택 + 직접입력 |
| 7 | 대극의 긴장 | 복수선택 + 직접입력 |

## 판정 규칙

- **주기능** = 네 기능 중 최고 점수. 태도와 결합해 융의 8유형 중 하나
- **보조기능** = 주기능과 다른 범주(판단 ↔ 지각)에서 높은 쪽
- **열등기능** = 주기능의 대극 기능 + 반대 태도
- 융에 따르면 개성화의 열쇠는 열등기능 발달에 있고, 주기능에서 곧장 갈 수 없으며 반드시 보조기능을 거친다. 결과의 7일 훈련은 이 경로를 따른다.

## 원칙

결과는 **진단이 아니라 가설**이다. 융의 유형론은 심리측정 도구로 검증된 것이 아니며, 화면에 이를 명시한다.
아니마/아니무스(성별 이분법)와 12원형(융 이론이 아닌 후대 각색)은 의도적으로 제외했다.

## 구성

`index.html` 한 파일. 빌드·서버·DB 없음.
답변은 브라우저 localStorage에만 저장되고 외부로 전송되지 않는다.

## 디자인

의식은 빛, 무의식은 어둠 — 단일 다크 팔레트에 네온을 빛으로 사용.
Pretendard(본문) + Martian Mono(수치), 필름 그레인, 헤어라인 구획.
모바일에서 한 문항이 한 화면에 들어가도록 설계.

## 공유 카드

결과 화면에서 트레이딩 카드(TCG) 형태의 PNG를 생성한다. 피드 4:5와 스토리 9:16 두 비율.

| 카드 요소 | 융 |
|---|---|
| 이름 / 수치 | 유형명 / 주기능 점수 |
| 일러스트 | 네 기능 대극 배치 (사고↔감정, 감각↔직관), 중심은 자기(Self) |
| 기술 2개 | 주기능 · 보조기능 |
| **약점** | **열등기능** |
| 저항력 | 보조기능 |
| 플레이버 | 개성화 선언문 한 줄 |

저장 경로는 세 갈래다. Web Share API가 있으면 공유 시트, claude.ai 아티팩트
안에서는 downloads 권한, 그 외에는 다운로드 링크를 쓴다. iOS Safari는 blob
다운로드를 무시하므로 새 탭으로 열어 길게 눌러 저장하게 한다.

무의식 5문항에 적은 내용은 카드에 들어가지 않는다.
