# 나의 자아 지형도

살아온 경험과 지금의 감정에서 **반복되는 것**을 찾아, 앞으로 선택하고 싶은 삶의 방향을 정리하는 자기탐색 도구.

- 16문항(선택) + 5문항(서술) · 약 8분
- 4개 축 위의 내 위치 → 16유형
- 반복해서 나타난 욕구 3가지 + 근거가 된 실제 답변
- 내 문장으로 고쳐 쓰는 자아 선언문
- 7일 안에 시험해볼 작은 행동 3가지

## 원칙

결과는 진단이 아니라 **가설**이다. 유형을 단정하지 않고, 사용자가 고른 답을 근거로 되돌려준다.

## 구성

`index.html` 한 파일. 빌드·서버·DB 없음. 외부 의존성은 Google Fonts 하나이며, 없어도 시스템 폰트로 동작한다.

답변은 브라우저 localStorage에만 저장되고 외부로 전송되지 않는다.

## 실행

파일을 브라우저로 열면 된다.
